# Консольный калькулятор на Python без сторонних библиотек

## Возможности
1. Определитель матрицы 
2. Транспонирование матриц
3. Умножение матриц
4. Умножение матрицы на число
5. Поиск обратной матрицы
6. Решение квадратных матриц

## Работа алгоритма
Обратная матрица считается через матрицу дополнений. Соответственно, системы уравнений считаются методом обратной матрицы. Определитель находится с помощью миноров, за исключением матриц 1-го и 2-го порядка.

## Ограничения, недочеты, планы
Код не округляет вывод, в дальнейшем ограничу четырьмя цифрами после запятой. Некоторые функции могут возвращать str, что лучше поменять на возврат ошибок.
